# Design System — EntreLinhas

## 1. Identidade visual

O EntreLinhas utiliza uma identidade visual editorial,
combinando tons neutros, elementos escuros e detalhes
em laranja para destacar ações importantes.

## 2. Paleta de cores

| Token | Valor | Aplicação |
|---|---|---|
| Primary | #9f3c16 | Botões e destaques |
| Secondary | #545f73 | Elementos secundários |
| Background | #f8f5f0 | Fundo geral |
| Surface | #ffffff | Cards e painéis |
| Text | #292929 | Textos principais |
| Border | #e4e2de | Bordas |

## 3. Tipografia

- Títulos: Playfair Display
- Textos: Plus Jakarta Sans

## 4. Espaçamentos

- Pequeno: 0.5rem
- Médio: 1rem
- Grande: 2rem

## 5. Componentes

- Botões principais e secundários.
- Cards de livros.
- Campos de formulário.
- Navegação principal.
- Painéis de autenticação.

## 6. Responsividade

O projeto utiliza Bootstrap 5.3.8,
unidades relativas e tipografia fluida.
